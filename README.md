# 銀河力学で学ぶ数値計算法
Numerical Methods for Galactic Dynamics

**学部生・大学院生向けの数値計算演習教材**です。銀河力学の質量モデル、Poisson 方程式、恒星軌道を題材に、数値解の誤差と収束を検証する方法を学びます。

- **著者:** 馬場淳一（鹿児島大学・国立天文台）
- **原教材:** 『銀河力学で学ぶ数値計算法』配布版 v1.2（2026年10月16日、104ページ）
- **対象:** 宇宙流体・重力多体系の数値シミュレーションを学び始める学部生・大学院生
- **関連書籍:** Barbara Ryden, *Celestial and Stellar Dynamics* (2025)

## 内容と学習順序

本編（第1～3章）は球対称系を題材に、数値計算法の基礎を学びます。付録A～Cは応用問題、付録Dは数値線形代数の補足です。

| 節 | 物理的な題材 | 主な数値計算法 |
| --- | --- | --- |
| 第1章：球対称質量モデルと数値積分 | Plummer・Hernquist・NFWモデル、内包質量、円運動速度 | 長方形則、中点則、台形則、Simpson則、誤差と収束 |
| 第2章：Poisson方程式と有限差分法 | 球対称質量分布の重力ポテンシャル・重力加速度 | 1次元Poisson境界値問題、有限差分、数値微分 |
| 第3章：球対称ポテンシャルと時間積分法 | 球対称重力場の恒星軌道 | Euler法、4次Runge–Kutta法、リープフロッグ法、保存量 |
| 付録A：軸対称円盤の質量積分と回転曲線 | 指数円盤、Mestel円盤 | 累積積分、格子収束 |
| 付録B：軸対称Poisson方程式の数値解法 | 軸対称重力場、Miyamoto–Nagaiモデル | 2次元有限差分、疎行列、格子収束 |
| 付録C：軸対称・非軸対称ポテンシャル中の軌道 | エピサイクル運動、軸対称・非軸対称軌道 | 軌道積分、保存量による検証 |
| 付録D：連立一次方程式の解法 | 第2章・付録Bの線形方程式 | Gauss消去法、LU分解、Jacobi法 |

## 学習方法

教材の各章を読み、対応するNotebookを最初から順に実行します。数値計算では、解析解との比較、保存量の診断、格子幅・時間刻みを変えた収束試験を重視してください。

Pythonの必要なパッケージは `requirements.txt` を参照してください。現在の依存関係は暫定版です。Notebookを取得後、クリーンな環境での一括実行を確認して更新します。
